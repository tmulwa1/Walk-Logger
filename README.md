# Walk-Logger
An app that imports files from walks and builds a personal dashboard.

## Features:
- Upload GPX files exported from Strava or any GPS app
- View route maps with markers
- Elevation profile charts
- Statistics dashboard (distance, duration, pace, elevation gain)
- Heatmap of all walks combined

## Technologies
- Python
- Flask
- GPXPY
- Folium
- Plotly
- Pandas
- SQLite
- SQLAlchemy

## How to run
1. Clone repository
2. Install dependencies: **pip install -r requirements.txt**
3. Run **python app.py**
4. Open **https://127.0.0.1:5000** in browser
